DIRECT VISUAL EDITING IN OVERLEAF

1. Open main.tex.
2. Click Visual beside Code at the top of the LEFT editor.
3. Click the report words on the left and type. All report text, including the
   cover, certificate, abstract, chapters and roles, is now together in main.tex.
4. Click Recompile to update the PDF on the right.

The right-hand PDF is the output preview. Edit in the left-hand Visual Editor.
Names, course code, guide/instructor and year are ordinary inline text in main.tex.
Layout and typography are in report_setup.tex, separate from the editable words.
The older frontmatter/metadata/abstract/body/reference files are reference copies;
their text is already included in main.tex. Change main.tex for the live report.
Charts/diagrams retain editable TeX and training data in data/training_history.csv.
The university logo is a replaceable file in assets/. Compiler: XeLaTeX.
The project uses Times New Roman when installed and TeX Gyre Termes otherwise.
